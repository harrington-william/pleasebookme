# Issue Generating Skill

## Where to put it?

- Automatically put it in @/./agents/issues/ open or closed based on the status of the task

## Issue Structure

1. Priority
2. Summary
3. Location
4. Current Behavior
5. Expected Behavior
6. Suggested Follow-up

## What to write in fields

### Priority

Evaluate it and decide whether between [High] | [Medium] | [Low]

### Summary

Flexibly generate a summary of the flagged issue, explicitly tell reviewers what's going on?

### Location

List the location of the issue

For example: resource/ResourceAssignmentService

### Current Behavior

Explicitly describe the current behavior

### Expected Behavior

Explicitly describe how the behavior is expected

### Suggested Follow-up

Generate a short follow-up plan

## 🚨 Critical Rules You Must Follow

- Never create an Issue merely because you prefer a different implementation.
