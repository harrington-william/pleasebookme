These principles are inspired by Enterprise IAM (Identity & Access Management) systems

# IAM Components

- Identity
- Authentication
- Session
- Authorization
- Policy
- Audit
- Federation (OAuth)

> Those become independent security subsystems in PleaseBookme
> 

---

# Why?

Because each of them answer a major security capabilities

For example:

- Identity answers WHO are you?
- Policy answers WHY can you do this ACTION on this specific RESOURCE under these CONDITIONS?
